# Perceptron Model on Iris Dataset

This project implements a **Perceptron** model using the classic **Iris dataset**, focusing on a binary classification task: distinguishing between *Iris-setosa* and *Iris-versicolor*. The model uses **two features** — *sepal length* and *petal length* — for simplicity and visualization.

The performance of the Perceptron is also **compared to an Adaptive Linear Neuron (Adaline)** model to evaluate convergence and classification accuracy under different learning conditions.

## Features Used:

* Sepal length
* Petal length

## Target Classes:

* Iris-setosa
* Iris-versicolor

## Project Highlights:

* Preprocessing and binary encoding
